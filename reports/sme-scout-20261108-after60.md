   - It is expanded in □⁻¹F. Maximal SUSY cancels the orders n < 4, and the n = 4 term is evaluated by a string-mode trace per unit symplectic volume.

   - Two consequences for NAMCG:
     - (i) The iε in the fermion log does not come from the bosonic regulator (their Eq. 4.15 regulates the bosonic matrices only). The published formula therefore already contains a *prescription* for the fermion determinant. That is the same gap 062 names ("involve no ε, which Definition (A) puts on bosons only").
     - (ii) The expansion is perturbative in □⁻¹F, so it cannot see exact zero modes. 061's Pf = 0 for the compact members is consistent with Steinacker 1510.05779, which leaves out the zero-mode sector.
3. **The literature does not use one-loop gravity to select signature.**

## 3. Ranked routes

### R1 (E/D1). A relative Pfaffian density on the doubleton member, defined and evaluated. Rank 1; one package, then stop E.
- **Hypotheses relaxed:** "Pfaffian at N = ∞" is replaced by
  - Pf_rel := exp ¼ τ[log(D̸² − iε) − log(□ − iε)],
  - with τ a stated semifinite trace per unit volume (the Plancherel trace of Spin(3,1) times the multiplicity label), and the Feynman prescription on the squared fermion operator taken from 2303.08012 Eq. 4.16 and *stated as supplied*.
- **Sub-lemmas, in order:**
  - (i) D_-D_+ = c(C₅ − C₄ − 2X) (062) commutes with the diagonal Spin(3,1). State its joint spectral measure with (C₄, P) on HS(H_n) ⊗ spinor, as a function of the remaining invariant (062's null-pair scalar product, which behaves like cosmic time).
  - (ii) The determinant-class condition: is ∫ log|λ| dμ finite near λ = 0? This is exactly 062 avenue 1 ("whether 0 is in the continuous spectrum"), recast as an integrability question that is decidable without a bounded inverse.
    - **MY CHECK (heuristic only):** 062 shows that the kernel set has Plancherel measure zero, and the SL(2,ℂ) Plancherel density is polynomial (062's Fioresi–Yuncken citation). So finiteness is plausible but not implied, because C₅ is not a function of (k, p).
  - (iii) Compare with the compact members, where exact zero modes make Pf_rel = 0 identically (061).
- **Expected outcome:** either a finite, non-zero density as a function of the time label (finishing 061's conditional separation in a stated sense), or an IR divergence that is itself a bounded no-go.
- **Constraints:**
  - γ > 0 breaks SUSY. 061's γTr(K+iε)⁻¹ term is regulator-dependent, so the n < 4 cancellation of 2303.08012 fails at O(γ). R1 must keep the fermion density separate from the bosonic one or state the γ order.
  - 061 notes that beyond one loop the compact members do not "drop out": the zero modes are absorbed by Yukawa vertices at higher order.
- **Feasibility:** medium. The algebra exists; the spectral measure in (i) is the real work.
- **Value:** finishes the 059–062 thread. It is not a breakthrough, and it is not a criterion item, since γ, h₀ and the fermions remain supplied.
- **Emergence:** preserved.

### R2 (G-derived). Matrix-derived boundary entropy density via a relational subsystem. Rank 2; best-verified non-E route.
- **Source:** Fliss–Frenkel–Hartnoll–Soni 2408.05274, SciPost Phys. 18, 171 (2025), verified (abstract).
  - In matrix QM, a relational subsystem's reduced state is approximately an incoherent sum over spatial subregions.
  - For semiclassical matrices the entropy is "dominated by the subregion with minimal boundary area".
  - Coarse-graining is "essential". The fuzzy sphere is the example.
  - Background: Frenkel–Hartnoll 2111.05967 (quantum-Hall matrix model, area-law term; search only); 1911.11145 (BFSS areas/entropies, SciPost Phys. 8, 057; search only).
- **Sub-lemma:** for a compact fuzzy factor or a time slice of the background, derive the entropy per unit boundary area. Identify which metric measures the "area", and show that it is NAMCG's composite metric, not the target contraction.
- **Constraints:**
  - Their setting has a Hamiltonian and a Hilbert space (matrix QM). NAMCG's integral has neither, so the subsystem must be built on the background's representation space.
  - The coarse-graining scale is a supplied input unless derived (rule 3).
  - **Emergence risk:** in 2408.05274 the area is measured in *target space*, i.e. with the supplied contraction. Using it unmodified would make η, not the composite metric, define the entropy density. The package must show the map to the emergent metric.
- **Feasibility:** medium for the entropy density on a compact fuzzy factor; low for the stationarity relation and the Λ_eff scaling.
- **Value:** the first step on G-derived. As a stand-alone result it is a conditional sharpening.
- **Also relevant to G:** 2303.08012's abstract states that the one-loop vacuum energy "does not act as cosmological constant" but stabilises the brane. This is a published constraint that any NAMCG Λ_eff statement touching the IKKT one-loop should cite.

## Findings
1. **Severity: blocking.** Location: `insert-r1.tex` (and the identical clause in `proposal-r1.md` §Insert): "the relative gap \(D=\max_k(e_{(k+1)q-1}-e_{kq})/\max_k|e_k|\)". Finding: as standardly read (1-based eigenvalue indices e_1..e_{2q}) this formula is not the statistic computed by any script: with k=1 it gives e_{2q−1}−e_q, the gap BETWEEN consecutive blocks (my check: 1.9473 ≠ 0 on a perfectly tiled spectrum), and its k=2 term is out of range; it equals the code (`e[k*q+q-1]-e[k*q]`, within-block spread, which does vanish at tiling) only under a 0-based subscript reading, nonstandard in the manuscript. Every D value quoted next to it (0.2986…, 0.1176, 0.1351, 0.054, the 6000-draw tiling test) comes from the within-block statistic. Reason: the manuscript would define a statistic different from the one generating all cited data. Required action: replace with a 1-based within-block-spread formula, e.g. `\(D=\max_{k=1,2}\bigl(e_{kq}-e_{(k-1)q+1}\bigr)/\max_j|e_j|\)`; regenerate insert bytes, rerun simulate_apply, update the POST hash contract.

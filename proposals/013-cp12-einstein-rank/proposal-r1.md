Because `{y^mu,y^rho} = -s M^{mu rho}/R^2` is fibre dependent, the fibre-integrated response is `int dmu delta K^{mu nu} = (m/R^2) d_rho (B^{nu;mu rho} + B^{mu;nu rho})`, `B^{nu;mu rho} = int dmu A^nu M^{mu rho}` (Liouville invariance; `m` is a function of `y` alone). Consequences, all exact: (a) fibre-constant fluctuations (the ordinary 4D gauge fields) and fibre harmonics `l != 1` give no linear response; (b) `d_mu d_nu (delta K^{mu nu}/m) = 0` identically (one linear constraint on the 10 components).
2. **Fibre geometry (checked numerically on an explicit realisation at two base points).** `M^{ab} y_b = 0` (`a,b = 0..4`), hence `T^mu = -M^{mu sigma} y_sigma / y^4`; over a base point the fibre is an `S^2` on which the six `M^{mu rho}` are first harmonics spanning a 3-dimensional space `W_y` (projected self-dual 2-forms of `y^perp`), the same space as the span of the `T^mu`. The 12 first-harmonic amplitudes `b in R^4 (x) W_y` are exactly the frame-type fluctuations `A^nu = kappa^nu_sigma(y) T^sigma` (`kappa` modulo `k^nu y_sigma`).
3. **Einstein rank (bounded positive result, kinematic).** Plane wave `e^{iq.y}`: `h^{mu nu} = q_rho (b^{nu;mu rho} + b^{mu;nu rho})`, `delta G_{mu nu} ~ eta eta h`. Exact upper bound: `q_mu q_nu h^{mu nu} = 0`, so the image has dimension `<= 9`. Exact-rational samples (4 base points, 12 generic `q`): image dimension 9; the linearised Einstein operator `E` of `eta` has rank **6** on the image (its image is all six conserved sources `q^mu T_{mu nu} = 0`), with kernel on the image of dimension 3. Six is the maximum, so by lower semicontinuity it is the generic rank. This is the first class in which neither the proportionality obstruction (011) nor the rank-3 obstruction (008/009) occurs, at the level of linear kinematics.
4. **Gauge structure.** For a matrix gauge transformation `A^nu = {Lambda, T^nu}`, the leading-order image is `h = q o (Lambda q)` with `Lambda^{mu rho} in W_y`: exactly the 3-dimensional space of transverse linearised diffeomorphisms (`xi.q = 0`), annihilated by `E` (exact-rational). The longitudinal diffeomorphism is not a matrix gauge transformation and is not in the image (it is the one direction removed by `q q h = 0`). Count: 12 amplitudes = 3 inert + 3 gauge + 6 gauge-invariant functions, against 6 conserved sources and against `10-4+1 = 7` for metric plus density in a diffeomorphism-invariant theory: the density is fixed by the Liouville measure and the metric image obeys one relation.
5. **Other fluctuations.** Transverse matrices with vanishing background bracket enter only quadratically. A fibre-dependent relabelling `y -> y + delta y` (fluctuation of the orbit embedding relative to the chart) acts at leading order as a pure linearised diffeomorphism with parameter `int dmu delta y` on the fibre-integrated tensor and on the fibre volume, so it adds no gauge-invariant function.
6. **Base functions (partial, conditional).** Among the SO(3,1)-vector generators `u^mu = alpha T^mu + beta y^mu`, the Poisson-limit operator `Box = eta_ab {T^a,{T^b,.}}` maps functions of `u` into functions of `u` iff `alpha = 0`: `Box y^mu = -y^mu/R^2`, `Box T^mu = -3 T^mu/R^2`, `K_u = alpha^2 eta_ab M^{a mu} M^{b nu} + beta^2 m^2 eta^{mu nu}` (the cross term vanishes by antisymmetry of `M^{mu nu}`), and the gradient-rank test shows `K_u` is fibre dependent for `alpha != 0`. So `y^mu` is selected by Lorentz covariance plus closure of the reduced operator. This does not derive the orbit, the matrices `T^a`, or that the matrix equations of motion single out this reduction.

**Step 1: linear response.** `K^{mu nu}[X] = eta_ab {X^a,y^mu}{X^b,y^nu}` with `X = T + A`. Linear term: `eta_ab({A^a,y^mu} s eta^{b nu} m + s eta^{a mu} m {A^b,y^nu}) = s m ({A^nu,y^mu} + {A^mu,y^nu})`. Transverse matrices `X^i` with `{X^i,y} = 0` in the background: `K` gains `sum_i {X^i,y^mu}{X^i,y^nu}`, quadratic. Matrices with non-zero background bracket with `y` add `eta_IJ V^I V^J` to `K-bar` and leave the conformally flat class; not computed.

**Step 2: fibre integration.** Locally `L -> R^4`, `y: L -> R^4` is a submersion (rank 4, 011 item (3)) with 2-dimensional fibres; disintegrate the Liouville measure, `vol = d^4y dmu(y,f)` on the sheet `y^4 > 0` (the map is two-to-one onto the region, fold at `y^4 = 0`). For a test function `chi(y)`: `int vol chi {y^mu, A} = -int vol A {y^mu, chi} = -int vol A d_rho chi {y^mu,y^rho} = +s int vol A M^{mu rho} d_rho chi = -s int d^4y chi d_rho B^{mu rho}`, with `B^{mu rho}(y) = int dmu A M^{mu rho}` (used `int {a,bc} = 0`). Hence `int dmu {y^mu, A^nu} = -s d_rho B^{nu;mu rho}`, and since `delta K^{mu nu} = -s m ({y^mu,A^nu} + {y^nu,A^mu})` with `s^2 = 1` and `m` a function of `y` alone (011 item (4)), `int dmu delta K^{mu nu} = m d_rho (B^{nu;mu rho} + B^{mu;nu rho})` (restoring `R`: factor `m/R^2`). Applying `d_mu d_nu (1/m .)` gives zero by antisymmetry in `(mu,rho)`. This is the exact constraint of Result 1(b). It was derived by hand; not checked numerically (it is the Liouville property).

Locally, without integration by parts: for `A^nu = c^nu(y) F(f)`, `{A^nu,y^mu} = F {c,y^mu} + c {F,y^mu}`, the first term is `- s F d_rho c M^{rho mu}` (derivative of `c`), the second is algebraic in `c`. For `|q| ell >> 1` the first dominates, and its fibre average is `d_rho c <F M^{rho mu}>`. This is the same leading term as the exact formula; the algebraic terms are the subleading ones (not computed).

\paragraph{Conjugate-coordinate class: first-order response and linearised Einstein rank (conditional; not closure).}
Keep the conjugate-coordinate class of the preceding paragraphs in the Poisson limit: the leaf \(\mathbb{CP}^{1,2}\) with the Lie--Poisson bracket \(\{M^{AB},M^{CD}\}=s(\eta^{AC}M^{BD}-\eta^{AD}M^{BC}-\eta^{BC}M^{AD}+\eta^{BD}M^{AC})\), \(s=\pm1\) a convention, the matrices \(X^a=T^a+A^a\) with \(A^a\) arbitrary functions on the leaf, \(\eta=\mathrm{diag}(-1,1,1,1)\), and the base functions \(y^\mu\) held fixed. \paragraph{Why \(y^\mu=M^{\mu5}/R\) in this class (partial; conditional; not closure).}
The only \(\mathrm{SO}(3,1)\) vector generators of \(\mathfrak{so}(4,2)\) are \(T^\mu=M^{\mu4}/R\) and \(y^\mu=M^{\mu5}/R\), so take \(u^\mu=\alpha T^\mu+\beta y^\mu\).

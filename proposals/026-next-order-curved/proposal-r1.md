## Result

Target: Problem B (with F), the next order beyond Lambda^2 at the SUSY content (N_s = 6, n_D = 2) on a curved leaf (top avenue of 017/019/021/024). This is a derived structural result plus a bounded no-go. It closes nothing.

1. **Exact identity (Poisson-limit class, Euclidean, alpha = 1, one loop).** In the variables (G, rho, b), b_s = G_{st} Theta^{rt} d_r Theta_{mn} (so(4)-valued), the endomorphism of every sector is E = e 1 + X + b.b. At N_tot = 0, b = 0 (equivalently (N_s, n_D) = (6, 2)) the weighted sum of a_1 vanishes pointwise and the weighted sum of a_2, with no term dropped, equals (1/2) S, with
   S = tr_V[(b.b)^2] - n_D tr_D[(beta.beta)^2] = 8 tr a tr b + 16 tr(c c^T) >= 0
   (a, b, c = Gram matrices of the self-dual and anti-self-dual parts l, r of b; equality at a point iff b takes values in one su(2) factor there). Verified in exact rational arithmetic at random two-jets, Euclidean and eta = diag(-1,1,1,1). So the T-side log coefficient has no R^2, Ric^2, Riem^2, C^2, Euler, RE or Einstein-Hilbert term: it is a quartic in the torsion-like connection b. This upgrades the conjectural W_4 of 019 to an identity in the class (S/16 = (1/2)|l|^2|r|^2 + |K|^2).
2. **Exact J = 0 backgrounds (Euclid).** Pointwise rho Theta.Theta >= 4, equality iff Theta is (anti-)self-dual; then G_{mn} = rho delta_{mn} (conformally flat, R_G != 0 in general), g_rho flat, J = 0 (proof: J^nu = Box_G x^nu - G^{mu nu} d_mu ln rho). Closed SD omega = b_i eta^i iff div b = 0, d_4 b = -curl b. Explicit rotation-invariant example with a fixed plane. Non-BPS exact family omega = d(h(r) Lambda^3): r du/dr = -(1/2) u(u+2)(u+4), h = c(1 +- sqrt(1 - C/r^4)), G Berger-type with Weyl^2 = (3/2) u^2 (u+4)^2/(hr)^4 != 0; invariant under both coordinate-plane rotations, so cones around the fixed planes exist.
3. **The T side vanishes on every exact J = 0 background found** (a_1 and a_2 totals zero): for SD/ASD b is chiral automatically; on the d(h Lambda^3) family b is chiral exactly when J = 0 (off shell both parts, sampled).
4. **J = 0 does not force S = 0.** About constant Theta_bar, J = O(eps^2) is the source-free Maxwell equation D^m(D^m a^n - D^n a^m) = 0 for psi = x + eps a; quadratic solutions (36-dimensional) give constant b = O(eps) with both chiralities and S > 0; order eps^2 of J = 0 is solvable in an example. So the first non-vanishing T-side coefficient on a (formal) J = 0 background is (1/2) rho^2 S[b^(1)] eps^4 > 0 (Euclid), quartic, no EH.
5. **Where an EH term can sit.** Dimensional/identity argument: in the massless scale-free class every local order-Lambda^0 term has four derivatives. Mass insertion m_i^2 shifts a_2^(i) by -m_i^2 a_1^(i) + (1/2) n_i m_i^4 (exact check); the EH-type part is -(sum w n m^2/6) rho R[g_rho] - (sum w b m^2) rho^2 X, zero for a common mass, nonzero only for SUSY-breaking mass patterns. Steinacker's EH term (2303.08012 eqs 6.30-6.32) comes from the mixed quartic V_{4,mix} with a Kaluza-Klein mode sum; NAMCG's class (inert transverse matrices) has no analogue.
6. **A side:** not computed (precise reduction and missing step below). Hence no G_T vs G_A statement at log order; what is established is that the T side gives no area-type/EH log term at this content, while at Lambda^2 the (c_T, c_A) = (0, 2 or 0) mismatch of 017/019 is background independent (c_T = 0 pointwise on every background, c_A is local at Sigma).

### 1. The exact a_2 identity
Sector i has omega = d phi 1 + b^(i), phi = -(1/2) ln rho the same for all sectors, b^(i) = b^a T_a^(i) in a representation of so(4) (vector; spinor lift; trivial for scalars and ghosts). Manuscript convention O = -D^2 + E, E = div omega + omega.omega = e + X + b.b, e = -(1/2) Box ln rho + (1/4)|d ln rho|^2, X = div b - d ln rho . b linear and traceless. Then
tr E^2 = n e^2 + 2 e tr(b.b) + tr X^2 + 2 tr(X b.b) + tr((b.b)^2) (+ 2 e tr X = 0).
Weighted by w_i: sum w n = N_tot = 0 kills e^2; sum w I_i = b = 0 kills e tr(b.b) and tr X^2 (tr_i(T_a T_b) = I_i delta_ab); tr(X b.b) is a symmetrised cubic invariant, zero for so(4) = su(2) + su(2). Also sum w tr Omega^2 = (sum w I) F.F = 0 (the abelian part of Omega is a curl of a gradient), sum w tr E = 0 from a_1, and the box terms and tr1-curvature terms are multiples of sum w tr E and sum w n. Hence sum w a_2 = (1/2) sum w tr (b.b)^2 = (1/2) S exactly. Verified in exact arithmetic (`chk_a2_quartic`, Euclid; `chk_a2_lorentz`, eta = diag(-1,1,1,1), Cl(3,1) gammas), including the separate vanishing of sum w tr E, sum w tr Omega^2, sum w (curvature) pieces.
S in terms of chirality: vector b.b = -(tr a + tr b) 1 + 2 c_kl eta^k etabar^l, Dirac upper block beta = -r tau, lower beta = -l tau, giving tr_V = 4 (tr a + tr b)^2 + 16 tr(c c^T), tr_D = 2 (tr a)^2 + 2 (tr b)^2; at n_D = 2 the squares cancel: S = 8 tr a tr b + 16 tr(c c^T) (`chk_S_formula`, general n_D formula to 2e-14). For positive-definite G (Euclid) S >= 0, zero iff l = 0 or r = 0 at the point.

Uniqueness of the content: on eight SD/ASD backgrounds the weighted a_2 vanishes only for (N_s - 2, n_D) = (4, 2), i.e. (N_s, n_D) = (6, 2) (`sd_content_scan`, exact solve).

### 2. J = 0 backgrounds
(a) Identity (exact at random two-jets): J^nu = Box_G x^nu - G^{mu nu} d_mu ln rho. (b) Pointwise bound: Theta^{mn}Theta^{mn} = 4(|theta_+|^2 + |theta_-|^2), |Pf| = ||theta_+|^2 - |theta_-|^2|, so rho Theta.Theta >= 4 with equality iff SD or ASD (`chk_sd_system`). For SD Theta: Theta Theta^T = |theta|^2 1, G^{mn} = delta/rho, sqrtG = rho^2, so Box_G x^nu = d_nu ln rho / rho = G^{mn} d_m ln rho, J = 0 (proof, no computer). (c) Closed SD omega = b_i eta^i iff div b = 0, d_4 b = -curl b (ASD: +curl), checked on the polynomial solution spaces (`chk_sd_system`). The solution space is infinite-dimensional, e.g. polynomial b of any degree. G = |b|^2 delta, g_rho = delta exactly (Riemann of g_rho = 0 at three points, `run_sd_example`), Weyl = 0, R_G != 0. Rotation-invariant example: b_1 + i b_2 = -(x1 + i x2)(x3 - i x4), b_3 = 1 + x3^2 - x4^2 (closed, J = 0, invariant under the (12) rotation, `run_sd_example.out.txt`); more invariant polynomial families in `sd_rot_invariant.py`. (d) Non-BPS: for omega = d(h(r) Lambda^3) the jets give J_r = -(10h^2h' + 2h^2 r h'' + 4h r h'^2 + r^2 h'^3)/(2h^2(2h + r h')^3), other components zero, `run_su2_J`. With u = r h'/h: r u' = -(1/2) u(u+2)(u+4); integrating, (u+2)^{-2} = (1 - C r^{-4})/4, and h = c (1 + sigma sqrt(1 - C/r^4)) (ODE residual 0 symbolically; J = 0 at a generic Cartesian point to 1e-34 by 60-digit finite differences, `chk_closed_form`, `chk_J_cartesian`). u = 0, -4 are SD and ASD; u = -2 degenerate (Pf omega = 2h^2 (u+2)); the four (sigma, sign C) branches cover u in (0,inf), (-2,0), (-inf,-4), (-4,-2). G = alpha^2 (dr^2 + e3^2) + beta^2 (e1^2 + e2^2) with alpha = r h' + 2h, beta = 2h, alpha/beta = sigma/s (verified at a generic point to 1e-50, `chk_G_frame`); R_G(u) = -3u^2(3u^2+16u+24)/(8(u+2)^2)/(hr)^2, Weyl^2 = (3/2) u^2 (u+4)^2/(hr)^4 (symbolic at r = h = 1, scale covariance checked exactly at two (r0, h0, u), `chk_su2_scaling`). Theta is invariant under both coordinate-plane rotations (`chk_su2_toric`), each fixing a plane pointwise, so the fixed-state replica around Sigma exists; the intertwining identity O_v Gr = Gr O_s - {J,.} is local and holds on the cover minus Sigma with J = 0. The domain/zero-mode/tip conditions of 017 remain assumptions.
(e) Totals on these backgrounds: a_1 and a_2 weighted sums vanish identically on the SD family (`run_sd`) and on the d(h Lambda^3) family on shell for all u (`an_su2_unit`: sqrtG a_2 totals 0 while single-sector values are nonzero rational functions of u). Reason: chirality. For the d(h Lambda^3) family with J = 0, tr a = 0 (b anti-self-dual-valued) also for non-collinear SU(2)-invariant solutions with h_i(r), i = 1..3 (ODE solved for h'': J_3 = 0 forces z = 0, `run_su2_general_J`, `an_su2_general`), whereas off shell |l|^2, |r|^2 > 0 (`an_su2_offshell_chirality`). The on-shell chirality in these classes is numerical (sampled), not proved.
(f) Non-chiral J = 0: with psi = x + eps a, Theta = (psi^* omega_bar)^{-1} (exactly Poisson), Theta^(1) = -(Theta_bar D a - ...) and J^(1)^n = D^m D^m a^n - D^n D^m a^m, D^m = Theta_bar^{m r} d_r: source-free Maxwell in the flat coordinates y with d/dy^m = D^m (validated against exact jets at small eps, `euclid_maxwell_perturbation` Step 1: J/eps = -J1, B/eps = B1 to 1e-14). Quadratic a: 36-dimensional solution space for the tested Theta_bar; b^(1) constant and S > 0 on five random draws (4e3 - 5.5e3 in the units used). Second order: with a_2 cubic, the 16 equations J^(2) = 0 have rank 15 = rank of the augmented system, i.e. solvable (the one relation is the Noether identity D^nu J_nu = 0), `second_order_solvability`. So J = O(eps^3) and the O(eps^4) log density is (1/2) rho_bar^2 S[b^(1)] > 0, which also removes the gauge-function ambiguity (a term c^2 J.J of 017 would be O(eps^6)). Formal series only; convergence and globality not examined. (g) Gauge parameter: on globally J = 0 backgrounds the intertwining lemma gives Tr e^{-sO_kappa} = Tr e^{-sO_v} + Tr e^{-s O_s/alpha} - Tr e^{-s O_s}; the s^2 coefficient (log) is alpha-independent while the Lambda^2 and Lambda^4 coefficients scale as alpha and alpha^2 (consistent with (3+alpha)/6, 3+alpha^2). Conditional on 017's domain conditions.

### 3. Where EH can enter (Target 3)
Hypotheses of the no-go (all relaxations named): H1 Poisson limit (relax: Moyal); H2 Euclid (formal Lorentzian identity holds); H3 one loop; H4 alpha = 1 off shell (on shell alpha-independent); H5 massless: operators O_s etc. without scale (relax: masses); H6 inert transverse matrices and Yukawas dropped (relax: fuzzy K); H7 content (6, 2); H8 backgrounds in the classes above; H9 b treated as independent variable.
Mass insertion (`chk_mass_insertion`, all three sectors, exact): a_2(m) = a_2(0) - m^2 a_1 + (1/2) n m^4, a_1(m) = a_1 - n m^2. Log-order Einstein-type part of the weighted sum: -(sum w n m^2/6) rho R[g_rho] - (sum w b m^2) rho^2 X. Sign: with W = -(1/2) sum w int ds/s Tr e^{-sO}, 1/(16 pi G_T^{log}) = -(ln(Lambda^2/mu^2)/(32 pi^2)) sum w n m^2/6, positive only if the weighted fermionic masses exceed the bosonic. For uniform m the A-T mismatch is m^2 times the Lambda^2 mismatch (2 antiperiodic, 0 periodic), so a SUSY-preserving mass repairs nothing; with sector masses the mismatch is sum w_i (c^A_i - c^T_i) m_i^2 (per-sector c^A - c^T: scalar 0, connection +4, Dirac -1 antiperiodic / -2 unrotated per field). In heat-kernel language the Steinacker mechanism is an order-a_3 (E^3-type) term (b.b)(F_int Sigma)^2 times a KK sum of 1/mu^2 (consistent with c_K^2 ~ sum C^2/mu^2); this is my reading, not stated in the paper text I saw, and is not used in the LaTeX beyond the abstract-level statement. ### 4. A side (reduction, not computed)
At first order in E the log-order cone coefficient is controlled by the area coefficient of the same twisted block (Duhamel; dimension counting: a_2^Sigma contains E only linearly). So the E-part of the A-side log density has weights kappa_b = 1 for untwisted comps and kappa_D = -1/2 (antiperiodic Dirac, ratio of 1/3 to -2/3 in 019 units), not the statistical weights alone: sum w kappa tr E = 3 tr E_D at (6,2) (using sum w tr E = 0), versus 0 on the T side. Whether the curvature-projection terms [(R_ii - 2R_ijij) with spin-dependent cone numbers, and the R/6 term of the twisted Dirac block] cancel it is not known; the needed ingredients are the first-order cone a_2^Sigma of the twisted Dirac block with the torsionful connection b (Fursaev-Miele type, not verified here) and of the unrotated vector. Solodukhin's scalar formulas (tool-reported) would give the untwisted bosonic part. Surfaces Sigma exist on both families. I do not claim a log-level mismatch.

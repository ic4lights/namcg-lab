## Research and reasoning

### S7, verified before applying

The S7 old string is 195 bytes, sha256 `5c217b67...ec76`. The new string is 316 bytes, sha256 `4dd695f9...ef2c`. Both are read raw from review-r2.md, and both hashes match the ones printed there.

**G1 (index range).** The insert defines R_1 by A_0 = e^{-3 pi i/8} At_0 and A_i = e^{pi i/8} At_i. The CNT model of 2501.17798 sets A_0 = -i A_{d+1}. With A_mu = e^{pi i/8} At_mu for mu = 1,...,d+1, one gets A_0 = -i e^{pi i/8} At_{d+1} = e^{-3 pi i/8} At_{d+1}. That is R_1, with At_{d+1} the At_0 of the insert, as S7 states. Read at mu = 0, the old unrestricted display gives e^{pi i/8} At_0, which is i times the R_1 phase. So the old display was false in the insert's own notation, and S7 repairs it. Checked exactly in `s7_check_r3.py`: the difference is 0 and the ratio is i.

**G2 (Pfaffian).** For p = 4 the Euclidean weight on R_1 is e^{-S_E} times the Pfaffian there, as in the limit display of the insert. The CNT model and its rotation are bosonic, so the identification with 2501.17798 belongs to p = 0 only. S7 states both. My r2 note at L72 covered G1 only. It called the text "sufficient", and that was wrong by the standard the review applies.

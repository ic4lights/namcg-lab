# Proposal 022-Qinv-contraction, round 2

## Result
Bounded result; w is not derived. Round 2 applies review-r1 Findings 1-5 and minor items 6(a)-(e); 6(f) is noted only.
1. (Established, algebra plus numerics.) The contraction by Q^-1 is (y^4)^-2 [eta_ab D^a D^b + (y_a D^a)^2/l^2]. Its base symbol is the induced Euclidean metric g^-1 = eta + yy/l^2 of the hyperboloid, whereas the four-matrix kinetic tensor is K = m^2 eta = m^2 (g^-1 - yy/l^2). So it replaces the Lorentzian K by g and is not a Wick rotation. Here y.y = eta_AB y^A y^B (A = 0..4) = -l^2 on the orbit.
2. (No-go, bounded.) Hypothesis class: Poisson limit; four matrices T^a = M^a4; quartic term plus one bilinear term; background gauge function D_a A^a, ghost -Box, regulator a function of Box_X; constant index form eta_ab. Every operator is then a constant-coefficient polynomial in D^a, J^ab, i.e. an element of U(so(4,1)'), where so(4,1)' is the Lie algebra generated by D^a, J^ab (indices 0..4; M^a5, M^45 absent). (y_a D^a)^2 is not in U(so(4,1)'). Nothing is claimed beyond the class.
3. (Numerical.) Presentations X^A = M^(A c0): h > 0 for c0 in {0,5} (the only ones covered by the Definition), signature (2,2) for c0 in {1..4} (outside the Definition), never Lorentzian. For X^A = M^(A5): f1 = f2 (numerical), mu^2 = +4, exact identity H_V = C42 - C_G + C_Sigma + mu^2; the (k+1,k) component has eigenvalue mu^2 on polynomial vector fields.
4. (Stability data, now reported in full.) Degree-one vector polynomials (dim 75): formal H_V spectrum -8, -4, -2, +2, +4 with multiplicities 1, 5, 20, 14, 35, with no spectral meaning (non-normalisable). Compact so(6), five matrices, m^2 = -4: negative modes 49, 154, 385, 814 for N = 1..4 (35/140/371/800 at -4 plus 14 at -2), so this background is unstable. Four-matrix compact background: lowest eigenvalue -(N+3).
5. Sign and size of w: not determined. Label changes: none.

## Research and reasoning
The derivations of r1 are unchanged (scripts below). New in r2, from existing outputs:
- Finding 1. Q^-1 = (eta + yy/l^2)/(y^4)^2, so Q^-1_ab D^a D^b = (y^4)^-2 [eta_ab D^a D^b + (y_a D^a)^2/l^2]. The symbol of Q^-1 alone is g^-1. The bracket alone has symbol (y^4)^2 g^-1, differing by a non-constant factor.
- Finding 2. The G^dag G >= 0 sentence is dropped: a positive operator can remove negative modes and it does not bear on supply. The argument is structural: every listed operator is a constant-coefficient polynomial in D^a, J^ab; the non-constant functions y_a would need the missing generators M^a5, M^45. The so(4,2) Casimir has symbol -2 l^2 g^-1 but lies outside U(so(4,1)'). This is a statement about the listed operators, not a general theorem.
- Finding 3. check_extended_sets: the eight-matrix set {T^a, y^a} with y-block contracted by -eta is stationary with lambda_I w_I = -4 (mu^2 = -4), horizontal rank 6. Its induced contraction, signature and flux are not examined (avenue 2).
- Finding 4. check_P5_family_polynomial.out.txt: -8, -4, -2, +2, +4 with 1, 5, 20, 14, 35 (sum 75). Compact: 35+14, 140+14, 371+14, 800+14 = 49, 154, 385, 814 (quantum_compact_hessian outputs). The multiplicity sum is over 1 <= k <= N. Both compact backgrounds are unstable; -4 versus -(N+3) is not a stability advantage.
- Finding 5, items 6(a)-(d): wording in the block. 6(e): y_A D^A = 0 holds on the orbit (check_P5_vs_P4, 1.4e-13). In check_P5_exact_algebra item (2) the sampled polynomial has no M^(.5) factor, so the printed True is trivial and inconclusive; relabelled in check_P5_exact_algebra_r2.py (r1 script kept unchanged). 6(f): SO(4,1) covariance of the five-matrix presentation would reduce "identically f1 = f2" to a finite check on orbit representatives; not made a claim in the block.
- Fork. The no-go depends on: the Poisson limit, the four-matrix set, the single bilinear term, constant eta_ab, background gauge and regulator being functions of D^a, J^ab. Relaxations explored: matrix set (five matrices: constant contraction supplies the symbol, cost Euclidean g; eight/seven/nine-matrix extensions: checked, stationarity or rank problems), extra five-index term (quintic probe, outside eq:Smatrix, not proposed). Unexplored: regulator built from the so(4,2) Casimir, the -eta eight-matrix set. See the ranked list below.
